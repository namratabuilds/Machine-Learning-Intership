# Day 2 – Functions, Data Structures & File Handling

## Overview

On Day 2, I learned how to write reusable functions and work with Python's built-in data structures. I also practiced file handling, implemented a linear search algorithm, and learned how to handle runtime errors using exception handling.

## Topics Covered

* Functions
* Lists
* Tuples
* Sets
* Dictionaries
* File Handling
* Exception Handling

## Concepts Practiced

### Functions

* Creating functions using `def`
* Function parameters
* Return statements
* Local variables

### Lists

* Creating and updating lists
* Indexing and slicing
* Common methods:

  * `append()`
  * `insert()`
  * `remove()`
  * `sort()`
  * `reverse()`
  * `copy()`
  * `clear()`
* Finding maximum, minimum, sum, and length

### Tuples

* Creating tuples
* Indexing and slicing
* Tuple concatenation
* Converting between lists and tuples

### Sets

* Adding and removing elements
* Union
* Intersection
* Difference
* Symmetric Difference

### Dictionaries

* Creating key-value pairs
* Accessing and updating values
* Deleting items
* Checking keys
* Using `keys()`, `values()`, and `items()`

### File Handling

* Reading files
* Writing files
* Appending data
* Copying file contents

### Exception Handling

* `try`
* `except`
* `finally`
* Handling `ValueError`
* Handling `ZeroDivisionError`
* Handling `FileNotFoundError`
* Creating custom exceptions


## Learning Outcomes

By the end of Day 2, I was able to:

* Write reusable Python functions.
* Work with different Python data structures.
* Read from and write to text files.
* Handle common runtime errors using exception handling.
* Create custom exceptions for specific use cases.
