# Day 1 – Python Fundamentals

## Overview

The first day of the Machine Learning Training Program focused on learning the fundamentals of Python. I practiced the basic syntax, understood how different data types work, and wrote small programs to strengthen my problem-solving skills.

## Topics Covered

* Python installation and setup
* Variables and data types
* Type casting
* String operations
* Arithmetic, comparison, and logical operators
* Conditional statements (`if`, `elif`, `else`)
* Loops (`for` and `while`)
* Taking user input
* Basic program development

## Concepts Practiced

### Variables and Data Types

* Integer
* Float
* String
* Boolean
* Complex Numbers

### Type Casting

* Converting values using `int()`, `float()`, and `str()`
* Checking data types using `type()`

### String Operations

* Indexing and slicing
* String concatenation
* Common string methods:

### Operators

* Arithmetic operators

### Control Statements

* `range()`

## Programs Completed

### 1. Calculator

Developed a calculator that performs addition, subtraction, multiplication, and division based on user input. The program also handles division by zero.

### 2. Unit Converter

Created a menu-driven unit converter for:

* Kilometers ↔ Meters
* Kilograms ↔ Grams
* Celsius ↔ Fahrenheit

### 3. Grade Calculator

Built a program to calculate grades based on marks entered by the user.

### 4. Multiplication Table

Generated the multiplication table (1–10) for any number entered by the user.

### 5. Variable Swapping

Swapped the values of two variables using a temporary variable.

### 6. Star Pattern

Printed a star pyramid using nested loops.
