# Day 6 – Machine Learning Basics (Regression & Clustering)

## Overview

On Day 6, I started learning Machine Learning by implementing both supervised and unsupervised learning algorithms using **Scikit-learn**. I built multiple prediction models using **Linear Regression** and explored **K-Means Clustering** to group similar data points.

## Topics Covered

* Introduction to Machine Learning
* Supervised Learning
* Unsupervised Learning
* Linear Regression
* K-Means Clustering
* Model Training
* Prediction

## Concepts Practiced

### Linear Regression

* Understanding the relationship between input and output variables
* Training a regression model
* Making predictions using new data
* Visualizing regression results

### K-Means Clustering

* Understanding unsupervised learning
* Creating clusters based on feature similarity
* Training a K-Means model
* Predicting cluster labels

## Projects Completed

### Linear Regression Projects

#### 1. House Price Prediction

Predicted house prices based on the size of the house (square feet).

#### 2. Student Marks Prediction

Predicted students' marks based on study hours.

#### 3. Employee Salary Prediction

Predicted employee salary using years of work experience.

#### 4. Electricity Bill Prediction

Estimated electricity bills based on units consumed.

#### 5. Crop Yield Prediction

Predicted crop production using the amount of fertilizer applied.

#### 6. Fuel Consumption Prediction

Estimated fuel consumption based on the distance travelled.

---

### K-Means Clustering Projects

#### 1. 2D Point Clustering

Grouped simple coordinate points into different clusters.

#### 2. Customer Segmentation

Clustered customers using Age and Monthly Spending.

#### 3. Hospital Patient Grouping

Grouped patients based on their characteristics for basic profiling.

#### 4. Mobile Usage Analysis

Clustered users according to screen time and daily data usage.

#### 5. Gym Member Segmentation

Grouped gym members based on attendance and activity levels.

## Learning Outcomes

By the end of Day 6, I was able to:

* Understand the difference between supervised and unsupervised learning.
* Train and test Linear Regression models.
* Make predictions using regression algorithms.
* Apply K-Means Clustering to group similar data points.
* Use Scikit-learn to build simple machine learning models.
