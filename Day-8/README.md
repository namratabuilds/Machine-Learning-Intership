# Day 8 – Classification Algorithms

## Overview

On Day 8, I learned and implemented three popular machine learning classification algorithms: **K-Nearest Neighbors (KNN)**, **Decision Tree**, and **Random Forest**. I used these algorithms to solve different real-world classification problems and compared how they make predictions.

## Topics Covered

* K-Nearest Neighbors (KNN)
* Decision Tree Classifier
* Random Forest Classifier
* Classification Problems
* Model Training
* Prediction

## Concepts Practiced

### K-Nearest Neighbors (KNN)

* Understanding the KNN algorithm
* Choosing the value of **K**
* Training and testing a KNN model
* Making predictions based on nearest neighbors

### Decision Tree

* Rule-based classification
* Splitting data into decision nodes
* Building and testing a Decision Tree model

### Random Forest

* Ensemble learning
* Training multiple decision trees
* Improving prediction accuracy
* Making final predictions using voting

## Projects Completed

### K-Nearest Neighbors (KNN)

#### 1. Pass/Fail Prediction

Predicted whether a student would pass or fail based on study hours or marks.

#### 2. Fruit Classification

Classified fruits as **Apple** or **Orange** based on their weight.

#### 3. Weather Prediction

Predicted whether the weather would be **Cold** or **Hot** using temperature data.

#### 4. Plant Health Prediction

Classified plants as **Healthy** or **Dry** based on soil moisture levels.

#### 5. Traffic Congestion Prediction

Predicted traffic conditions as **Low Traffic** or **Heavy Traffic** using vehicle count.

---

### Decision Tree Projects

#### 1. Loan Approval Prediction

Predicted whether a loan application would be approved based on monthly income.

#### 2. Employee Promotion Prediction

Predicted employee promotion using years of work experience.

#### 3. Disease Risk Prediction

Classified patients as **Low Risk** or **High Risk** based on blood sugar levels.

---

### Random Forest Projects

#### 1. Mobile Battery Health Prediction

Predicted battery health as **Good** or **Poor** based on battery percentage.

#### 2. Exam Grade Classification

Predicted whether a student would pass or fail based on exam marks.

#### 3. Air Quality Classification

Classified air quality as **Good** or **Poor** using the Air Quality Index (AQI).
