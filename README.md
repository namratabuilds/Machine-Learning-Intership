# Machine Learning Training – 10 Days

This repository contains my work from a **10-day Machine Learning Training Program**, starting with Python fundamentals and gradually moving towards machine learning and a final project.

I have organized the work day-wise, including the concepts I learned, practice programs, and projects completed during the training.

## What I Covered

* **Day 1:** Python Fundamentals & Mini-Projects
* **Day 2:** Functions, Data Structures, File Handling & Exceptions
* **Day 3:** OOP & NumPy
* **Day 4:** Data Analysis with Pandas
* **Day 5:** Data Visualization with Matplotlib
* **Day 6:** Linear Regression & K-Means Clustering
* **Day 7:** Linear & Logistic Regression
* **Day 8:** KNN, Decision Trees & Random Forest
* **Day 9:** Model Evaluation & Feature Scaling
* **Day 10:** Student Performance Prediction – Capstone Project

## Projects

Some of the projects and exercises included in the training are:

* Calculator & Unit Converter
* Student Marks Analysis
* Data Handling & File Operations
* Regression-based Prediction
* KNN Classification
* Decision Tree & Random Forest Classification
* Model Evaluation
* **Student Performance Prediction using KNN**
