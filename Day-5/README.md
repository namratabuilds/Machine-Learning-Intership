# Day 5 – Data Visualization with Matplotlib

## Overview

On Day 5, I learned how to create different types of charts using the Matplotlib library. I explored various visualization techniques to represent data clearly and effectively by customizing charts with titles, labels, colors, legends, and gridlines.

## Topics Covered

* Introduction to Matplotlib
* Line Charts
* Bar Charts
* Pie Charts
* Scatter Plots
* Histograms
* Chart Customization

## Concepts Practiced

### Matplotlib Basics

* Importing `matplotlib.pyplot`
* Creating basic plots
* Understanding the plotting workflow

### Line Charts

* Creating line plots
* Adding titles and axis labels
* Customizing:

  * Colors
  * Line styles
  * Line width
  * Markers

### Bar Charts

* Vertical bar charts
* Horizontal bar charts
* Comparing categorical data
* Customizing bar colors

### Pie Charts

* Displaying percentage distribution
* Using `autopct` for percentage labels

### Scatter Plots

* Visualizing relationships between two variables
* Identifying trends in data

### Histograms

* Displaying frequency distribution
* Understanding data spread

### Chart Enhancements

* Adding legends
* Displaying gridlines
* Comparing multiple datasets on a single graph



## Learning Outcomes

By the end of Day 5, I was able to:

* Create different types of charts using Matplotlib.
* Customize charts with titles, labels, colors, markers, legends, and gridlines.
* Compare datasets using line and bar charts.
* Visualize percentage distribution using pie charts.
* Analyze relationships and data distribution using scatter plots and histograms.
* Present data in a clear and meaningful way.
