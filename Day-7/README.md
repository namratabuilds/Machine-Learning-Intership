# Day 7 – Linear & Logistic Regression

## Overview

On Day 7, I learned two important supervised machine learning algorithms: **Linear Regression** and **Logistic Regression**. I built prediction models for both continuous and binary outcomes using the Scikit-learn library and explored how machine learning models make predictions.

## Topics Covered

* Supervised Machine Learning
* Linear Regression
* Logistic Regression
* Model Training
* Prediction
* Model Evaluation
* Probability Prediction

## Concepts Practiced

### Linear Regression

* Understanding the relationship between input and output variables
* Training a regression model
* Predicting continuous values
* Finding model coefficient and intercept
* Evaluating model performance using the R² score

### Logistic Regression

* Binary classification
* Predicting class labels
* Understanding probability using `predict_proba()`
* Decision threshold for classification

## Projects Completed

### Linear Regression Project

#### 1. Student Marks Prediction

Built a Linear Regression model to predict student marks based on study hours. The model was evaluated using the R² score, and the coefficient and intercept were analyzed.

---

### Logistic Regression Projects

#### 1. Loan Approval Prediction

Predicted whether a loan application would be approved based on monthly income.

#### 2. Diabetes Risk Prediction

Classified whether a person is likely to have diabetes based on blood sugar levels.

#### 3. Spam Email Detection

Built a classifier to identify whether an email is spam based on spam-related word counts.

#### 4. Customer Churn Prediction

Predicted whether a customer is likely to leave based on the number of months since their last purchase.

#### 5. Binary Classification Practice

Implemented a basic Logistic Regression model to understand class prediction and probability estimation.

## Learning Outcomes

By the end of Day 7, I was able to:

* Understand the difference between Linear and Logistic Regression.
* Build regression and classification models using Scikit-learn.
* Make predictions using trained machine learning models.
* Interpret model coefficients and intercept values.
* Predict probabilities using Logistic Regression.
* Evaluate the performance of a Linear Regression model using the R² score.
